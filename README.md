# AJWorldTech Portfolio

A responsive corporate portfolio website for AJWorldTech, built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a modern browser. The site uses Google Fonts when an internet connection is available and has no build step or package dependencies.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Custom domain
When ready to use a domain, add the domain under **Settings → Pages → Custom domain** and follow GitHub's DNS instructions at your domain provider. Configure HTTPS after DNS verification.
